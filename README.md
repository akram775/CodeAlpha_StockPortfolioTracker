CodeAlpha Stock Portfolio Tracker

A simple and interactive Python-based command-line application designed to track stock investments, calculate total portfolio value, and automatically generate an investment report text file.

Features
Pre-defined Stock Prices:
 View available stocks (AAPL, TSLA, MSFT, GOOG, AMZN) and their current prices.
Dynamic Input:
Add multiple stocks and quantities interactively using a `while` loop.
Error Handling:
Validates stock availability and ensures entered quantities are greater than zero.
Portfolio Summary:
Displays a clean itemized list of all purchased stocks along with the grand total investment.
File Handling:
Automatically exports and saves the complete portfolio report to a `portfolio.txt` file.
